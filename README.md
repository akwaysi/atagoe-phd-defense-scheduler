# Akwasi Tagoe PhD Dissertation Defense Scheduler — One-Page Version

This version is redesigned to fit on one screen on normal desktop/laptop displays.

## Files

Upload these files to the root of your GitHub repository:

- `index.html`
- `style.css`
- `script.js`

## Meeting address

The meeting address is now controlled directly in `index.html`.

Find:

```html
<span id="meetingAddress" class="info-value">
  Meeting address to be confirmed
</span>
```

Replace only the text:

```html
<span id="meetingAddress" class="info-value">
  YOUR ACTUAL MEETING ADDRESS
</span>
```

You no longer need to change the address in `script.js`.

## Email delivery

Responses are sent through FormSubmit to:

`atagoe@uark.edu`

The first test submission may trigger a FormSubmit activation email.
Activate it before sharing the site with your professors.
